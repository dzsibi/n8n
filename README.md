# n8n Fork

This is a fork of the official [n8n repository](https://github.com/n8n-io/n8n).

This fork extends the GCP Secrets Manager provider with label filtering,
Application Default Credentials support, and explicit project ID configuration.

For the official source code, documentation, and current upstream development,
use the [upstream n8n repository](https://github.com/n8n-io/n8n).
